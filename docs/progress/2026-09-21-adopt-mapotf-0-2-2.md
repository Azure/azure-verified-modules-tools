## Validation

The [v0.2.2 release](https://github.com/Azure/mapotf/releases/tag/v0.2.2)
includes [Azure/mapotf#131](https://github.com/Azure/mapotf/pull/131). The
release initially shipped with no assets; assets and `checksums.txt` were
published later the same day.

- `.\scripts\Update-AvmPins.ps1 -Mapotf 0.2.2` fetched and validated
  `checksums.txt` and regenerated all six platform SHA256 hashes.
- `Install-AvmTool -Name mapotf` installed and SHA256-verified the Windows
  amd64 0.2.2 binary from the pinned URL; `mapotf version` reported
  `Terraform v1.16.2 on windows_amd64` as expected for this build.
- Full-stage `Invoke-AvmTransform -Ecosystem terraform -ThrottleLimit 4`
  against the `terraform-azure-avm-res-mock` fixture (root + 3 examples, the
  same fixture and profile set used in the 2026-09-19 slice), with
  `MAPOTF_PROVIDER_SCHEMA_CACHE_DIR` pointed at an isolated, empty directory:
  - Cold (empty schema cache): 33.96s, `Status=pass`, 0 changed files.
  - Warm (schema cache populated by the cold run): 6.31s, 6.57s, 4.08s
    (mean 5.65s), all `Status=pass`, 0 changed files.
  - Against the prior 0.2.1 baseline (mean 44.79s, from the 2026-09-19
    slice), the warm full-stage mean is **87.4% faster**.
- Correctness: transformed the fixture with the released 0.2.1 binary
  (schema cache disabled, matching pre-adoption behaviour) and separately
  through the engine with 0.2.2 (warm cache). SHA256 per `.tf` file across
  root and all three examples: **zero differences**.
- `./build.ps1 pre-commit`: succeeded, 5 tasks, 0 errors, 85 warnings (same
  known/expected component-tier warnings seen in the 2026-09-19 slice; no
  new categories).
- `git diff --check`: passed.
- `./build.ps1 integration` was **not** run locally (documented as unreliable
  on Windows dev boxes — see `docs/quality-standards.md`). Correctness was
  instead verified directly via `Invoke-AvmTransform` against the same
  fixture used by CI's integration tier, plus the byte-for-byte SHA256
  comparison above. CI's `integration` job on all three operating systems
  is the authoritative check for this change.
