**Status**: complete

## Outcome

Set the Terraform example telemetry variable generated by the mapotf profile to
default to enabled. The reusable Terraform workflow already forces
`TF_VAR_enable_telemetry: 'false'` globally, so no workflow change is needed:
e2e runs stay opted out while every other consumer of the transform now
defaults to telemetry enabled. An earlier revision of this slice added a
redundant `enable-telemetry` workflow input and per-step override; that change
was reverted back to the pre-existing global env var once the duplication was
spotted.
