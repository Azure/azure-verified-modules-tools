## Outcome

Make Bicep pre-commit compile local module source into its generated main.json
through the pinned CLI, and make pr-check compare the same build output
without changing the module or cache. Support root and child selection,
missing-file and drift failures, explicit compiler errors, and safe
ShouldProcess/WhatIf writes. This read-only compilation path supplies the
later in-memory README renderer. Do not deploy, publish, or migrate the
registry README generator in this slice.
